## 2026-05-14: [design]
### Decision
Use a two-column utility UI for the v1 matcher.

**Context:**
User needs immediate job description input and fit report review, not a marketing page.

**Alternatives Considered:**
- Landing page first - slows core workflow.
- Multi-step wizard - unnecessary for single JD paste flow.

**Outcome:**
Input panel sits left, report panel sits right on desktop, stacked on mobile.
